  1. Using the program

Building from the command line

COM Manifest Studio can make a program's manifest without a window - for a build script or a build server:

COMManifestStudio.exe /build <program.exe> [/copy] [/compile] [/embed] [/log <file>]

The program's manifest must already be in COM Manifest Studio, with its components: open it in the program once and add the fragment files. After that, the build needs no window.

What it does

  1. It always builds the manifest file and has mt.exe check it, as Build does.
  2. /copy copies the COM files that are missing from the program's folder.
  3. /compile compiles the program with the DataFlex version its workspace is for. When the program's project settings embed the manifest (EmbedManifestFile=1 in its .cfg file), the compiler puts the manifest into the program as it builds it. If they do not, the build stops and says so.
  4. /embed puts the manifest into the finished program with mt.exe.

It stops at the first step that fails. Each step is checked by what is on disk afterwards: the manifest validated, no component file missing, and the program carrying the manifest's COM classes.

Use /compile rather than /embed. /embed rewrites a finished program file, and an antivirus program can refuse that - see When an antivirus program blocks Embed.

The log

No message box and no question is shown. Every message goes to the log, and every question the program would have asked is written there with the answer the build gave it. The log is the file /log names, or else a file named after the program with ".manifest-build.log", in the program's folder. Its last line says RESULT=SUCCESS or RESULT=FAILED, with the exit code.

The exit code

  • 0 - everything asked for was done and checked.
  • 1 - a step failed; the log says which, and why.
  • 2 - the build could not start: no program on the command line, an unknown switch, the program file is not there, or COM Manifest Studio has no manifest for it.

Example

COMManifestStudio.exe /build "C:\Projects\Order\Programs\Order64.exe" /copy /compile /log "C:\Build\Order-manifest.log"
