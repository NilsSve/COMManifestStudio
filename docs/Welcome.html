Welcome

A DataFlex program that uses COM components - ActiveX controls such as the Codejock command bars and grids, in .ocx and .dll files - normally needs those components registered with Windows before it can run. Registering takes an administrator, and one installation can break another: a program that installs an older or newer copy of a component changes it for every program on the computer.

A Windows program can do without registration. When its manifest - a small XML file, or the same text built into the .exe - names the COM components it uses, and the component files are in the program's own folder, Windows loads them from there. The program then carries its own private copies, and it can be installed by copying its folder. Microsoft calls this an isolated application.

COM Manifest Studio makes that manifest for you. You choose a program and the COM components it uses, and the program:

  • builds the program's manifest from one small fragment file per component,
  • checks that the component files are in the program's folder, and copies the missing ones,
  • puts the manifest into the program, by compiling it or by embedding it into the finished .exe,
  • and starts the program, so you can see that it works.

The main window shows these as five steps. To make your first manifest, see Quick start.
