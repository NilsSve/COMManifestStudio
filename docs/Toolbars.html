  1. Using the program

Menus and toolbars

Every command is in the menu bar. The toolbars hold the commands used most.

File

  • New Project... - a wizard that makes a manifest for a program (Quick start).
  • Select Manifest... - choose one of the manifests COM Manifest Studio keeps.
  • Browse for Manifest File... - open a manifest file on disk.
  • Save, delete and clear the manifest, and exit the program.

Manifest

The commands of the five steps: Build manifest, View or edit the manifest file, Check and copy COM files..., Embed in the program, Compress the program, Compile the program and Run the program.

Fragments

  • Add fragment files... - choose fragment files from your library for the manifest that is open.
  • Edit fragment file - open the fragment file selected in the list in the editor.
  • Create a fragment file... and Create for a whole folder... - make fragment files for components that have none.
  • Get new files from GitHub... and Share your files on GitHub...

These are described in The fragment library.

Components

For the COM component of the fragment file selected in the list: Check registration (is it registered with Windows?), Register and Unregister. A program with a manifest does not need its components registered; these commands are for making fragment files and for testing.

Tools

  • Open the program folder, Open the fragment library folder and Open the COM library folder - in Windows Explorer.
  • Settings... - see Settings.
  • Show the start dialog - the dialog the program shows when it starts.

Help

This help, the online help in your web browser, a video on making a manifest for the standard Codejock components that come with DataFlex, Microsoft's article on side-by-side assemblies, a page on GitHub to suggest a feature or report a bug, and the program's source code on GitHub.

The toolbars

  • Find - first, previous, next and last manifest, and the list of manifests.
  • File - clear, save and delete.
  • Edit - cut, copy, paste and delete.
  • Help - Settings, this help (with the online help and the other help links in its drop-down), and the GitHub and Ko-fi buttons.
