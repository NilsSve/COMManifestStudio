What's new

Version 2026

  • A new main window. It shows the work as five steps, from choosing the components to a test run, and it says at each step what is done and what comes next. The window follows the Light, Dark or Windows theme (Settings).
  • Menus instead of the old toolbars. Every command is in the menu bar, described in Menus and toolbars.
  • 64-bit programs. The manifest is built for the program's platform (x86 or amd64), a fragment file for the other platform is reported before anything is written, and the 64-bit component files are copied.
  • The fragment library is on GitHub. Get new files from GitHub downloads fragment files that are new or that differ from yours, and you share your own through GitHub. They used to be on VDF-Guidance.
  • Create fragment files for a whole folder - for example for a new Codejock release - in one go.
  • Compile and run the program from the window, with the DataFlex version its workspace is for.
  • Building from the command line. COMManifestStudio.exe /build makes the manifest without a window, for build scripts and build servers.
  • Antivirus programs. When an antivirus program refuses to let Embed change a program file, COM Manifest Studio says so and explains what to do instead (When an antivirus program blocks Embed).
  • This help is new, and it is also on the web.
