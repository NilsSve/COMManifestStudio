  1. Using the program

64-bit programs

A 64-bit program needs the 64-bit build of each COM component, and a manifest that says it is for the amd64 platform. COM Manifest Studio reads the platform from the program file itself (or, for a program not compiled yet, from a name ending in 64.exe, as DataFlex names its 64-bit programs).

  • Choose the 64-bit fragment files. For Codejock components their names contain x64, for example Codejock.CommandBars.Unicode.x64.v24.3.0.txt. The 32-bit and the 64-bit file of one component declare the same COM classes, so a manifest can hold only one of them; Build stops and names them if you chose both.
  • Build writes the manifest for the program's platform. If a fragment file is for the other platform, it says which before anything is written, and asks whether to write the manifest anyway. A 64-bit program cannot use a 32-bit component, nor the other way round.
  • Copy COM files copies the 64-bit component files. Codejock's 32-bit and 64-bit files register the same class IDs, so COM Manifest Studio looks for a component by its own file name rather than trusting the first file the registry names.

COM Manifest Studio itself is a 32-bit program, also when it works on a 64-bit program.
