  1. Using the program

Quick start

This page takes you through your first manifest. For what each step does, see The five steps.

1. Open the program's manifest

Choose one of these:

  • File > New Project... starts a wizard. It asks for the program (the .exe file) and whether it already has a manifest file. If it has none, the wizard creates one - with "DPI aware" in it if you tick that option. Then it lets you choose the fragment files.
  • File > Browse for Manifest File... opens a manifest file on disk: the file with the program's name and ".manifest" added, for example Order.exe.manifest. The DataFlex Studio keeps it in the workspace's AppSrc folder.
  • File > Select Manifest... lists the manifests COM Manifest Studio already keeps, so you can go back to one you worked on before.

2. Choose the components

Click Add files... in step 1 of the main window (or press F4 in the list), and choose one fragment file for each COM component the program uses. A fragment file has the name of the component's file with ".txt" instead of ".ocx" or ".dll". You can also drag the files from Windows Explorer onto the list. If you cannot find a component's fragment file, see The fragment library.

3. Build the manifest

Click Build in step 2. COM Manifest Studio writes the components into the manifest file and has Microsoft's mt.exe check the result. The previous manifest file is kept as a backup, with the date and time in its name.

4. Copy the COM files

Click Copy COM files in step 3. It checks that each component's file is in the program's folder, and copies the ones that are missing.

5. Get the manifest into the program, and test it

  • If the program is compiled with "Embed manifest file" on in its project settings (EmbedManifestFile=1 in its .cfg file), compile it: the compiler puts the manifest into the program. Use Compile in step 5.
  • Otherwise, use Embed in step 4.

Then click Run in step 5 and check that the program starts and that its controls appear.

That is all a program needs: the manifest in the program, and the component files in its folder. The program can now be installed by copying its folder, without registering the components.
